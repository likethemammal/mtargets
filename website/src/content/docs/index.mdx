## Naming

| Name | Meaning |
|------|---------|
| **Metric Targets** | This library (TypeScript API + CLI) |
| **mtargets** | npm package `mtargets`, CLI `mtargets`, and file format (`apiVersion: mtargets/v1`, `*.mtargets.yaml`) |

```yaml
apiVersion: mtargets/v1
kind: MetricSuite
metadata:
  id: checkout-quality
  title: Checkout quality
spec:
  subjects: [...]
  indicators: [...]
  objectives: [...]
```
